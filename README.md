# 🏠 Household Manager (고급 가계부 매니저)

**Household Manager**는 기존의 복잡한 스프레드시트 관리 방식을 탈피하여, 강력한 데이터 시각화와 직관적인 사용자 경험(UX)을 제공하는 **데스크톱 GUI 가계부 애플리케이션**입니다. 

구글의 **Material Design**을 모티브로 한 세련된 UI와 함께, 여러 개의 가계부를 독립적으로 관리할 수 있는 기능을 제공합니다.

---

## ✨ 주요 기능

### 1. 멀티 가계부 관리
* 하나의 프로그램으로 여러 개의 독립적인 가계부(예: 개인용, 사업용, 부부공용)를 생성하고 관리할 수 있습니다.
* 각 가계부 간의 데이터는 완벽하게 격리되어 저장됩니다.

### 2. 스프레드시트 방식의 데이터 입력
* **직관적인 편집**: 엑셀처럼 표의 셀을 직접 클릭하여 데이터를 입력하고 수정할 수 있습니다.
* **수동 저장 시스템**: 각 행별 저장 버튼(✅/❓)을 통해 데이터의 보존 상태를 실시간으로 확인하고 제어할 수 있습니다.
* **지능형 드롭다운**: 설정에서 정의한 카테고리와 결제수단이 계층형 드롭다운으로 자동 연동됩니다.

### 3. 강력한 시각화 리포트
* **월별 분석 대시보드**: 고정비/변동비 분석, 예산 집행률(%), 카테고리별 지출 분포, 일별 지출 추이 등을 차트로 제공합니다.
* **소비 패턴 인사이트**: 현재 지출 데이터를 바탕으로 과소비 지점과 주요 소비처를 분석한 텍스트 리포트를 생성합니다.
* **연도별 추이**: 1년 동안의 수입과 지출 흐름을 비교 분석할 수 있습니다.

### 4. 체계적인 예산 및 자산 설정
* **12개월 예산 그리드**: 한 해의 예산을 항목별로 세밀하게 계획하고, '일괄 적용' 기능을 통해 빠르게 설정할 수 있습니다.
* **계층형 분류 관리**: 대분류와 중분류를 트리(Tree) 구조로 관리하여 복잡한 지출 항목을 체계화합니다.

### 5. 데이터 이관 및 편의 기능
* **엑셀 임포트**: 기존에 사용하던 `.xlsx` 가계부 데이터를 단 한 번의 클릭으로 이관할 수 있습니다.
* **다크/라이트 모드**: 사용자의 환경에 맞는 세련된 테마 전환 기능을 지원합니다.
* **키보드 단축키**: 엔터 키 추가, 화살표를 이용한 날짜 조절 등 키보드 중심의 빠른 워크플로우를 제공합니다.

## 🛠 기술 스택

- **Language**: Python 3.10+
- **GUI Framework**: PyQt6
- **Database**: SQLite3
- **Visualization**: Matplotlib
- **Excel Handling**: openpyxl

---

## 🚀 실행 방법

### 1. 의존성 설치
본 프로젝트는 가상환경(venv) 사용을 권장합니다.
```bash
# 가상환경 생성 및 활성화
python -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate   # Windows

# 필수 라이브러리 설치
pip install -r requirements.txt
```

### 2. 프로그램 실행
```bash
python main.py
```

## 📂 프로젝트 구조

```text
household/
├── main.py              # 메인 컨트롤러 및 UI 진입점

│   ├── report_tab.py    # 데이터 시각화 리포트
│   └── migration_util.py # 엑셀 임포트 유틸리티
└── household.db         # 로컬 데이터베이스 파일
```
